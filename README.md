MeshWave is a desktop music experience for artists, producers, and listeners who want to share and discover music directly with each other.

Build your own library, play tracks with rich visuals, and connect to a community-powered network where music travels between people—not platforms.

## Why musicians love MeshWave

- 🎧 **Beautiful playback experience** with waveform view, comments, and timeline interaction
- 📀 **My Music workspace** to organize tracks and albums with metadata editing
- 🌐 **Community sharing** across a decentralized peer-to-peer mesh
- 💬 **Track conversations** with version-aware comments
- ❤️ **Like, follow, and discover** music in a social, artist-friendly flow
- 🛠️ **Runs locally on your machine** with your own folders and settings

## Quick start

1. Clone the repository
2. Build the app
3. Run MeshWave and point it to your music folder
4. Start playing, organizing, and sharing

## Build

```powershell
dotnet build MeshWave.slnx
```

## Test

