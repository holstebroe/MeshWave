# MeshWave User Guide

## Navigation

Top menu:

- Home
- Library (community)
- Local Music (your local managed collection)
- Playback
- Settings

## Settings

In Settings you can:

- Choose the MeshWave base folder
- Configure supported audio extensions (persisted)
- Save settings to `%APPDATA%\MeshWave\settings.json`

## Local Music Import

1. Open **Local Music**
2. Click **Import Local Music**
3. Select source folder
4. Watch import progress (current file, total, remaining)
5. Cancel import if needed

Imported files are copied and organized automatically by artist/album.

## Library Browsing

Both Library and Local Music support hierarchy:

1. Select artist
2. Select album
3. Browse tracks
4. Double-click a track to play

Lists are scrollable when content is larger than the panel.

## Playback

- Icon-based controls: Play / Pause / Stop
- Playback continues while switching tabs
- Selecting a new track stops previous playback and starts the new one
- Cover art is shown when available
- Waveform loads from cache, or appears once generated in background
- Comments can be added during playback
- Timeline markers are displayed on waveform for comments

## Notes

- `Peer Music` is intended for community-managed content.
- Some social/profile and sync features are still in progress.
